## 기본 개념

- 파일 시스템: 컴퓨터에서 데이터 저장 및 검색 방법을 제어하는 체계
- 파티션: 하나의 디스크를 여러 개의 파일 시스템으로 구성하는 단위. 여러 개의 디스크를 하나의 파티션으로도 통합 가능하며, 운영체제는 각 파티션을 별도의 디스크처럼 취급한다.
- 볼륨: 디스크 상 논리적인 분할 단위. 섹터 또는 클러스터들이 모여서 이루어진 큰 덩어리

## 리눅스 내 파티션 종류

- 주 영역 파티션
- 확장 영역 파티션
- 논리 영역 파티션

## 리눅스 내 디스크 표현 방식

```plain text
s d a 3
```

1. `s`: `s`일 경우 SCSI, SATA, SSD 등의 디스크를 의미하고, `h`일 경우 IDE, ODD 등의 디스크나 CD 리더기를 의미
2. `d`: disk 의미
3. `a`: 디스크의 개수. 알파벳 순서에 따라 각각 존재
4. `3`: 디스크당 파티션의 개수

## 파티션 구성 절차

1. 전원 off 상태에서 디스크를 장착
2. 추가된 디스크에 파티션 구성: `fdisk`
3. 파일 시스템 생성, 포맷: `mkfs`
4. 새로운 마운트 포인트를 만들고 파티션을 마운트: `mount`
5. 자동 연결을 위한 `/etc/fstab` 등록

## 리눅스 내 LVM

LVM은 리눅스에서 디스크나 대용량 스토리지를 유연하게 확장할 수 있게 다룰 수 있는 기술이다. 물리 디스크를 볼륨 그룹으로 묶고 논리 볼륨으로 분할하여 확장성을 높일 수 있다.

1. 하드 디스크 장착
2. 하드 디스크의 파티션을 LVM 타입으로 생성: `fdisk`
3. 물리 볼륨 생성: `pvcreate`
4. 만든 물리 볼륨을 볼륨 그룹으로 모아 설정: `vgcreate`
5. 위 볼륨 그룹에서 논리 볼륨을 원하는 크기대로 설정: `lvcreate`
6. 파일 시스템으로 포맷 후 마운트: `mkfs`, `mount`
