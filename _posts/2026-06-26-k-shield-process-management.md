실행 중인 프로그램을 프로세스라고 한다. 실행 시 PID가 할당되어 관리된다.

프로세스는 실행 중인 프로그램, PCB를 지닌 프로그램, 프로그램 카운터를 지닌 프로그램, 능동적 개체로 순차적으로 수행하는 프로그램 모두 해당된다.

## 포어그라운드와 백그라운드

```shell
bg   # 포어그라운드 프로세스를 백그라운드 프로세스로 전환
jobs # 백그라운드로 실행 중인 프로세스나 중지된 프로세스의 목록 출력
fg   # 백그라운드 프로세스를 포어그라운드 프로세스로 전환
```

## 데몬

데몬(Daemon)은 사용자가 직접적으로 제어하지 않고, 백그라운드에서 돌면서 여러 작업을 하는 프로그램이다.

`syslogd`나 `sshd`와 같이 보통 `d`를 이름 끝에 달고 있으며, 일반적인 프로세스로 실행된다.

## 데몬 제어 명령어

```shell
systemctl start [데몬명]   # 데몬 시작
systemctl stop [데몬명]    # 데몬 중지
systemctl restart [데몬명] # 데몬 재시작
systemctl reload [데몬명]  # 데몬 설정 변경 리로드
systemctl status [데몬명]  # 데몬 상태 확인
```

## 우선순위

- PRI: 운영체제에서 참고하는 우선순위 값. 낮은 값일수록 우선순위가 높다.
- NI: 낮은 값일수록 우선순위가 높고, root만 값을 낮출 수 있다.

## `/proc`

새로운 프로세스가 생성되면 `/proc` 디렉터리에 PID와 동일한 서브 디렉터리가 생성되고, 그 안에 해당 프로세스에 관한 정보를 저장한다.

## `cron`

`cron`은 유닉스 계열 컴퓨터 운영체제의 시간 기반 작업 스케줄러이다. 고정된 시간, 날짜, 간격에 주기적으로 실행할 수 있도록 스케줄링을 수행한다. `/etc/crontab` 파일에 의해 구동된다.
